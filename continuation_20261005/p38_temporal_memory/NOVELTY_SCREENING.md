# P38 mechanism screen

No novelty claim is authorized. Temporal memory for tracking is established, and
MOTIP, MCTR, FusionTrack, and the local P2/TEC experiment are adjacent or direct
mechanism precedents. P38 is narrowed to an auditable hypothesis: a zero-initialized
current/history residual adapter trained on the existing MDMT detector-feature
cache with cross-view masked identity CE and a causal history-consistency term.

The screen therefore asks only whether this changed observable/learning target
improves held-out association proxy under the frozen split. A pass would authorize
an implementation audit and a separate P26 host-front-door test; it would not
establish originality or official MOT effectiveness.

Nearest controls:

* P1 independent embedding: frozen representation control.
* P1C fixed temporal mean: non-learned history control; already a positive retrieval
  diagnostic, but not a trainable method.
* P2/TEC: prior temporal objective that failed its calibration gate; P38 differs
  by making history an explicit causal input to the output representation.
* P14 frozen DINO residual: strongest held-out representation control, but its host
  transfer failed; it is not silently reused as the current method.
