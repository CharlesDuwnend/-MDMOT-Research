# P27 FIT-only temporal observation diagnostic

Frozen before execution, 2026-10-05. Scope: 15 FIT pairs / both views / complete frozen stream frame ranges from `p0/data/ASSOCIATION_DIAGNOSTIC_SPLIT.json`. No calibration/dev/official-val/test data is used in the computation. CPU only; no images, GPU, model inference or training.

Inputs are the frozen detector-row labels bound by `DETECTION_LABELS_MANIFEST.json`, their aligned indices and train streams, and raw FIT XML bound by `sequences_train.json`. Reuse `build_detection_labels.read_xml`: stream frame = XML frame + 1; exclude `outside=1`; supported classes pedestrian/person=0, bicycle=1, car=2. “Visible annotated” means an outside=0 valid box, and includes XML `occluded=1`. It does not mean visually unoccluded.

For each supported-class GT box in the full stream range, CURRENT is true iff the frozen label table contains its `(frame, raw_local_identity, detector_class)` with `matched_gt=true`, `gt_class=detector_class`, and `matched_iou>=0.5`. Verify label SHA, label/aligned/stream row keys, unique detector-row keys, and one-to-one matched GT keys. Do not rematch, use tracker IDs, or mask local identities because of cross-view label conflicts.

Within a single `(pair, view, raw_local_identity, class)`, history is valid only within the current contiguous annotated segment. Fixed descriptive horizons H=1,4,8 ask whether a CURRENT detection occurred at any strictly prior annotated frame in `[t-H,t-1]` within that segment. A missing annotation/disappearance resets history. No future detections, subsequent recovery, cross-view identity, or current detection enters these history flags. These are ORACLE observation diagnostics, not deployable recovery or performance predictions.

Record first annotation (separately marking stream-start left censoring), reappearance after an annotation gap, first detector observation in the segment and in the local annotation lifetime, prior detector frame, contiguous annotation age, and prefix miss-run age. Partition missed observations into annotation birth; reappearance; continuous never-detected segment; continuous prior detection older than 8 frames; continuous prior detection within 8 frames. Birth is an annotation event, not verified physical entry or tracker birth. Report XML occlusion and GT pixel minimum-side bins `<16`, `16..32` (16 inclusive, 32 exclusive), and `>=32`.

Full miss-run lengths and recovery/termination endpoints are retrospective summary-only outputs. They never enter the strictly-past row flags. Their observation mass must equal CURRENT-missing count.

An optional cross-view appendix intersects same-frame annotated boxes with equal raw ID and equal normalized XML label, excluding class conflicts. It asks, among both-current-missing observations, whether either/both view histories have prior H evidence; each view independently resets at its annotation gaps. This is only the `same_label_equal_id` annotation convention, not verified physical identity, calibration, synchronization, or evidence transfer.

Detector compatibility restriction: old stage1 streams apply `detector_score_min=0.1` after detector output (`export_gt_free_bytetrack.py`). P26 uses native post-NMS output with a reported default 0.05 threshold; exact P26 parity is audited separately. This diagnostic describes only the hashed old streams and must not be presented as exact P26 missing rate, recovered detections, FGFA benefit, MDA/HOTA/IDF1 gain, or a novelty claim. There is no score/window sweep.

Required invariants before execution: current exclusion/strict past; horizon boundaries; future suffix invariance; annotation-gap reset; annotation birth distinct from reappearance and detector-first-seen; identity/class isolation; rejection of duplicate detector keys and duplicate matched GT keys. After execution, independently recompute all histories from saved rows and confirm complete input/output hashes, FIT-only scope, stream coverage, row/count conservation, disjoint miss categories, and run mass.

Outputs: compressed per-GT NPZ per sequence, compressed retrospective miss-run NPZ, optional cross-view NPZ, summary JSON, per-sequence/per-pair CSV, deterministic case CSV, readable REPORT.md, invariant verification JSON, and final RECEIPT.json with input/code/result SHA-256. Receipt excludes itself; `RECEIPT.sha256` binds it.
