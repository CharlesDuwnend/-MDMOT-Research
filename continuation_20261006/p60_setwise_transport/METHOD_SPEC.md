# P60 Setwise Identity Transport (screening)

P60 tests a set-level identity operator on the frozen P23 head. For each same-frame,
same-class, opposite-view candidate group, it forms the complete cosine affinity
matrix and applies a fixed-temperature entropic transport normalization with uniform
row and column marginals. The transport score is used only to re-rank the existing
candidate edges; no detections, labels, thresholds, geometry, or global IDs are
added. Fit/calibration pseudo-PID supervision is not used in this first signal.

This is a narrow operator screen, not a novelty claim. A positive frozen signal would
authorize a CPU contract and a preregistered adapter only; it would not authorize
P26 attachment or official evaluation.
