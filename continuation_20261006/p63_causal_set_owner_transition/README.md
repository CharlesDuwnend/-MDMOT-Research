# P63 CSR-POT

P63 is the first candidate selected from a mature P26 failure decomposition. It targets false support correspondences in the actual MIA projective refresh, not a generic descriptor residual. A reliability head reweights native support pairs, a weighted DLT recomputes the projective state, and a set-level owner transition applies conflict-free updates.

The pair23 temporal diagnostic is positive against the native control and shows a small extra gain over a fixed residual operator. It remains a mechanism candidate: no formal MOT result, official validation/test, GPU training, or novelty claim is authorized until pair-level expansion and full P26 host replay.
