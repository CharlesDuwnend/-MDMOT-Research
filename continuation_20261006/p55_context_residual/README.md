# P55 CVCR screening

P55 tests whether a target-masked local context residual can add identity
evidence to the mature P26 association path. The directory intentionally starts
with specification, collision screen, and an input-only context data audit.
Large context arrays and checkpoints stay local and are indexed by compact
receipts. Read `METHOD_SPEC.md`, `NOVELTY_SCREENING.md`, and `PREREG.json` before
interpreting any result.
