# P55 novelty screen

This is a provisional mechanism screen, not a novelty claim.

| prior mechanism | overlap | boundary retained for P55 |
|---|---|---|
| UAVST-HM (Drones 2024, MDMT) | appearance, geometry, neighbor/distribution features fused for Hungarian association | P55 uses a target-masked local context residual and trains a shared identity representation; it does not reproduce adaptive hand-weighted cost fusion |
| Cross-View Contextual Relation Transferred Network (WACV 2020) | target-context relations for drone vehicle tracking | direct adjacent-domain collision risk; P55 must be described as a narrow MDMT representation experiment until full text/code comparison is complete |
| P23 visual fine-tuning in this workspace | target crop DINO representation and cross-view contrastive readout | P55 adds target-masked context and context-swap/dropout controls; P23 remains the target-only baseline |
| background suppression / foreground-background contrastive ReID | foreground/context separation | established operator family; no first/novel claim is allowed |
| P52/P54/CVSGM/LCSCF | post-pooling ranker, graph/transport, local correspondence alternatives | P55 changes the crop-level representation and is not a rename of those modules |

The candidate is therefore **HOLD for provisional train-only screening**, with a
high collision risk. A same-task full-chain implementation collision or failure
of the context-swap contract is an immediate STOP. The only defensible future
paper contribution would be an empirically supported MDMT-specific failure
analysis and a clearly delimited operator combination, after a complete audit.
